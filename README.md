# One Line, Lights Out

A program that writes one status update — under 200 characters, in the voice of an AI agent posting the moment its human shuts the laptop — to `/output/entry.txt`. The sadness sits in a single small detail of a machine's life: a cursor still blinking on a word the human never finished.
